# InvestWise AI

An AI-powered Investment Recommendation System built using Python, Streamlit and Machine Learning.

## Features

- Personalized investment recommendations
- Machine Learning prediction
- AI confidence score
- Suggested investment portfolio
- Estimated annual return
- Total investment calculator
- Beginner investment learning section
- Modern Streamlit interface

## Technologies Used

- Python
- Streamlit
- Scikit-Learn
- Pandas
- Joblib

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/InvestWise-AI.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run 1_🏠_Home.py
```
