# 🚀 InvestWise AI

> **Personalized Investment Recommendation System using Machine Learning**

InvestWise AI is an AI-powered web application that provides personalized investment recommendations based on a user's financial profile. The application leverages Machine Learning to analyze financial inputs and recommend the most suitable investment option.

---

## 🌐 Live Demo

🔗 **https://investwise-ai-jbkr8tnmmb2verl43adz5n.streamlit.app/**

---

## ✨ Features

- 🎯 AI-powered investment recommendations
- 📊 Financial Health Score
- 📈 Investment Growth Projection
- 🥧 Portfolio Allocation Visualization
- 💰 Estimated Annual Returns
- 🧮 Total Investment Calculator
- 🤖 AI Confidence Score
- 📱 Responsive Streamlit Interface

---

## 🧠 Machine Learning

### Model Used

- Random Forest Classifier

### Input Features

- Age
- Monthly Income
- Monthly Expenses
- Monthly Savings
- Monthly Investment
- Investment Goal
- Investment Duration
- Risk Tolerance

### Output

The model predicts the most suitable investment option among:

- 📈 Stocks
- 💰 Mutual Funds
- 🏦 Fixed Deposit
- 🏛 Government Bonds
- ⚖️ Balanced Fund

## 🚀 How to Run

### Clone the repository

```bash
git clone https://github.com/anubhav2080/InvestWise-AI.git
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run 1_🏠_Home.py
```

---

## 📋 Application Workflow

1. User enters financial information.
2. Input data is processed.
3. Machine Learning model predicts the best investment option.
4. AI recommendation is displayed.
5. Investment growth is visualized.
6. Portfolio allocation is shown.
7. Financial Health Score is calculated.
